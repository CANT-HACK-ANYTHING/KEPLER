## 1. Supabase Database Naming System (For Your Database Teammate)

The backend uses **exact snake_case table and column names** across **4 Supabase tables** linked by `student_id`. Your teammate can run the SQL script below directly in **Supabase Dashboard → SQL Editor**:

### Table Naming Overview
1. **`chat_logs`** — Stores every student question and Socratic AI response.
2. **`student_scores`** — Stores quiz, unit test, assignment, and mock exam marks per subject/topic.
3. **`teacher_feedback`** — Stores the Admin/Teacher's opinions, qualitative notes, and requested support level (`high_support`, `moderate_support`, `independent_challenge`).
4. **`student_analytics`** — Stores the computed 4-factor analysis, `support_needed_score` (`0–100`), `support_tier`, and `adaptive_directive` (unique per `student_id`).

### Ready-to-Run Supabase SQL Script
```sql
-- 1. chat_logs: Student <-> Socratic Tutor conversation history
create table if not exists chat_logs (
    id bigint generated by default as identity primary key,
    student_id text not null,
    student_name text not null,
    question text not null,
    ai_response text not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
create index if not exists idx_chat_logs_student_id on chat_logs(student_id);

-- 2. student_scores: Academic test/quiz/assignment marks per subject
create table if not exists student_scores (
    id bigint generated by default as identity primary key,
    student_id text not null,
    student_name text not null,
    subject text not null,              -- 'Mathematics' | 'Science' | 'Social Science' | 'English' | 'Hindi'
    topic text default 'General',
    score numeric not null,
    max_score numeric not null,
    percentage numeric not null,        -- Normalized 0-100
    assessment_type text default 'quiz',-- 'quiz' | 'unit_test' | 'assignment' | 'mock_exam'
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
create index if not exists idx_student_scores_student_id on student_scores(student_id);

-- 3. teacher_feedback: Admin/Teacher opinions & support directives for a student
create table if not exists teacher_feedback (
    id bigint generated by default as identity primary key,
    student_id text not null,
    student_name text not null,
    teacher_name text default 'Class Teacher',
    subject text default 'General',
    support_level text default 'moderate_support', -- 'high_support' | 'moderate_support' | 'independent_challenge'
    teacher_support_rating numeric default 50,     -- 0-100 scale of how much extra Socratic support is needed
    opinion_notes text not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
create index if not exists idx_teacher_feedback_student_id on teacher_feedback(student_id);

-- 4. student_analytics: Synthesized 4-factor analysis & Socratic support profile
create table if not exists student_analytics (
    id bigint generated by default as identity primary key,
    student_id text not null unique,
    student_name text not null,
    overall_score_avg numeric default 0,
    answering_capacity_score numeric default 0,
    overall_enthusiasm_score numeric default 0,
    support_needed_score numeric default 50,       -- 0-100 composite support score
    support_tier text default 'guided_support',    -- 'intensive_scaffolding' | 'guided_support' | 'independent_challenge'
    capacity_level text default 'developing',      -- 'strong' | 'developing' | 'needs_attention'
    enthusiasm_level text default 'moderate',      -- 'high_curiosity' | 'moderate' | 'low_enthusiasm'
    subject_breakdown jsonb default '{}'::jsonb,
    strengths_and_gaps jsonb default '{}'::jsonb,
    latest_teacher_opinion jsonb default '{}'::jsonb,
    adaptive_directive text default '',
    teacher_summary text default '',
    updated_at timestamp with time zone default timezone('utc'::text, now()) not null
);
create index if not exists idx_student_analytics_student_id on student_analytics(student_id);
```

## 3. Frontend Developer Integration Guide (Keypoints & Snippets)

CORS is enabled for **all origins (`*`)**. All numeric scores (`overall_score_avg`, `answering_capacity_score`, `overall_enthusiasm_score`, `support_needed_score`) are normalized on a **`0–100` scale** for direct binding to progress bars and radar charts.

### Ready-to-Use Frontend JavaScript / React API Client

```javascript
const API_BASE = "http://localhost:8000";

// 1. Student Socratic Chat (Adaptive based on 4-factor profile)
export async function sendChatMessage(studentId, studentName, message, history = []) {
  const res = await fetch(`${API_BASE}/chat`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ student_id: studentId, student_name: studentName, message, history }),
  });
  return await res.json();
  // Returns: { reply, status, detected_subject, support_tier, support_needed_score }
}

// 2. Teacher/Admin: Record a Student Test/Quiz Score
export async function submitStudentScore({ studentId, studentName, subject, topic, score, maxScore, assessmentType = "quiz" }) {
  const res = await fetch(`${API_BASE}/scores`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      student_id: studentId,
      student_name: studentName,
      subject,
      topic,
      score,
      max_score: maxScore,
      assessment_type: assessmentType,
    }),
  });
  return await res.json();
}

// 3. Teacher/Admin: Submit Opinion & Support Level for a Student
export async function submitTeacherFeedback({
  studentId,
  studentName,
  teacherName = "Class Teacher",
  subject = "General",
  supportLevel = "high_support", // "high_support" | "moderate_support" | "independent_challenge"
  teacherSupportRating = 80,     // 0 - 100
  opinionNotes,
}) {
  const res = await fetch(`${API_BASE}/admin/feedback`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      student_id: studentId,
      student_name: studentName,
      teacher_name: teacherName,
      subject,
      support_level: supportLevel,
      teacher_support_rating: teacherSupportRating,
      opinion_notes: opinionNotes,
    }),
  });
  return await res.json();
}

// 4. Teacher/Admin: Get Full 4-Factor Analysis for One Student
export async function fetchAdminStudentAnalysis(studentId, refreshAi = true) {
  const res = await fetch(`${API_BASE}/admin/analysis/student/${encodeURIComponent(studentId)}?refresh_ai=${refreshAi}`);
  return await res.json();
}

// 5. Teacher/Admin: Get Class-Wide Dashboard & Students Needing Attention
export async function fetchAdminClassDashboard() {
  const res = await fetch(`${API_BASE}/admin/analysis/class`);
  return await res.json();
}

// 6. Student View: Get Personalized Progress & Study Guidance Card
export async function fetchStudentGuidance(studentId) {
  const res = await fetch(`${API_BASE}/student/${encodeURIComponent(studentId)}/guidance`);
  return await res.json();
}
```
