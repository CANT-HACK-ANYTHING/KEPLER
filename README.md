# Class 10 CBSE AI Tutor — Backend API

A lightweight, guardrailed Python backend for a Class 10 CBSE Socratic AI Tutor built with **FastAPI**, **Google Gemini API** (with optional NVIDIA NIM fallback), and **Supabase**.

## 1. Local Setup Steps

### Step 1: Create & Activate Virtual Environment
```powershell
cd C:\Pysustain
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### Step 2: Install Dependencies
```powershell
pip install -r requirements.txt
```

### Step 3: Configure Environment Variables
Copy `.env.example` to `.env`:
```powershell
Copy-Item .env.example .env
```

Edit `.env` and fill in your keys:
```env
# Google Gemini API Configuration
GEMINI_API_KEY=AIzaSy_your_actual_gemini_key_here
GEMINI_MODEL=gemini-2.5-flash

# Supabase Configuration
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_SERVICE_KEY=your_supabase_service_role_key_here

# Server Configuration
PORT=8000
HOST=0.0.0.0
```

### Step 4: Set Up Supabase Table (`chat_logs`)
Open your **Supabase Dashboard → SQL Editor** and run:
```sql
create table if not exists chat_logs (
    id bigint generated by default as identity primary key,
    student_id text not null,
    student_name text not null,
    question text not null,
    ai_response text not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```
> **Note:** Even if Supabase is not configured yet, the backend will still run and respond to students without crashing.

## 3. Frontend Developer Integration Guide

CORS is enabled for **all origins (`*`)**, so your React, Next.js, Vue, or mobile frontend can call the API directly.

### Endpoint 1: `GET /health`
Checks if the backend server is alive.

**Response (`200 OK`):**
```json
{
  "status": "healthy",
  "service": "Class 10 CBSE AI Tutor",
  "provider": "Google Gemini",
  "model": "gemini-2.5-flash"
}
```

---

### Endpoint 2: `POST /chat`
Sends a student's message (and optional conversation history) to the AI Tutor.

#### Request Headers
```http
Content-Type: application/json
```

#### Example Request Body (First Message — No History)
```json
{
  "student_id": "std_101",
  "student_name": "Aarav",
  "message": "Can you help me solve x^2 - 5x + 6 = 0?"
}
```

#### Example Request Body (Follow-up Message — With History)
```json
{
  "student_id": "std_101",
  "student_name": "Aarav",
  "message": "I think the two numbers are -2 and -3.",
  "history": [
    {
      "role": "user",
      "content": "Can you help me solve x^2 - 5x + 6 = 0?"
    },
    {
      "role": "assistant",
      "content": "Let's factor this quadratic equation together! To split the middle term, can you think of two numbers that multiply to +6 and add up to -5?"
    }
  ]
}
```

#### Example Success Response (`200 OK`)
```json
{
  "reply": "Spot on, Aarav! Since -2 and -3 multiply to +6 and add to -5, how can you rewrite the equation by splitting -5x into those two terms?",
  "status": "success"
}
```

#### Example Fallback Response (`200 OK` — When AI Times Out or Hits Rate Limit)
The server catches AI errors so the frontend never receives an unhandled `500` crash:
```json
{
  "reply": "I took a little too long thinking about that. Could you ask again or try rephrasing your question?",
  "status": "fallback"
}
```

#### Example Validation Error Response (`422 Unprocessable Entity`)
Returned if `message` is empty, whitespace-only, or exceeds 1,000 characters:
```json
{
  "detail": [
    {
      "type": "value_error",
      "loc": ["body", "message"],
      "msg": "Value error, Field cannot be empty or contain only whitespace.",
      "input": "   "
    }
  ]
}
```

### Ready-to-Use Frontend JavaScript / React Snippet

```javascript
async function sendChatMessage(studentId, studentName, message, history = []) {
  const response = await fetch("http://localhost:8000/chat", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      student_id: studentId,
      student_name: studentName,
      message: message,
      history: history, // Array of { role: "user" | "assistant", content: "..." }
    }),
  });

  if (!response.ok) {
    const errorData = await response.json();
    throw new Error(errorData.detail?.[0]?.msg || "Failed to send message");
  }

  const data = await response.json();
  return data; // { reply: "...", status: "success" | "fallback" }
}
```

## 5. Deployment Notes (Render / Railway)

### Deploying to Render
1. Push this project to a GitHub repository.
2. In Render, click **New + → Web Service** and connect your repository.
3. Configure the service settings:
   * **Runtime**: `Python 3`
   * **Build Command**: `pip install -r requirements.txt`
   * **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
4. Under **Environment Variables**, add:
   * `GEMINI_API_KEY` = `your_gemini_api_key`
   * `GEMINI_MODEL` = `gemini-2.5-flash`
   * `SUPABASE_URL` = `https://your-project-ref.supabase.co`
   * `SUPABASE_SERVICE_KEY` = `your_supabase_service_role_key`

### Deploying to Railway
1. Push this project to a GitHub repository.
2. In Railway, click **New Project → Deploy from GitHub repo**.
3. Under **Settings → Deploy → Custom Start Command**, set:
   ```bash
   uvicorn main:app --host 0.0.0.0 --port $PORT
   ```
4. Under **Variables**, add:
   * `GEMINI_API_KEY`
   * `GEMINI_MODEL` (`gemini-2.5-flash`)
   * `SUPABASE_URL`
   * `SUPABASE_SERVICE_KEY`
